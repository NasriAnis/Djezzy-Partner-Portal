# Djezzy Partner Portal — User Guide

What feature does the user get access to:
- Request to create stores
- Buying/Drafting offers to a specific store
- Selling offers to clients
- Check for his draft and stock

# Request to create stores
Under the account section at `/account/<account_name>/` there is the possibility to creating a store by filling the forma that appear. The store will be reviewed by a commercial then accepted or refused.

The user will receive a notification at the header of the site with a comment from the commercial if the store get refused.

# Buying/Drafting offers to a specific store
At the offers page a user can choose a specific offer and choose any of the plans available at `/offers/<offer>/` page. The user can either request directly a plan or place it in a draft for later.

An offer transaction is always placed in pending and has to be reviewed by a commercial before usage. Also depending on the user location a specific quota is placed by the commercials.

# Selling offers to clients
A user can sell offers to a client at `account/manage/` page there he can choose the store, the plan to sell and a number.

# Check for his draft and stock
A user can check for his offers in any status and stock at `account/draft-stock/`
